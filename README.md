## Описание файла  
**SearchScreen.js** – это экран приложения, реализованный с использованием React Native. Он отвечает за получение данных о криптовалютах через API, отображение их в виде списка карточек и реализацию функционала поиска и добавления в избранное.

---

## Импортируемые модули и библиотеки

- **React и хуки:**  
  ```js
  import React, { useState, useCallback, useEffect, useRef, useMemo } from "react";
  ```  
  Здесь используются стандартные хуки React для управления состоянием, эффектами, мемоизацией и ссылками:
  - **useState:** управление локальным состоянием (например, список криптовалют, поисковый запрос, ошибки, избранное).
  - **useCallback:** мемоизация функций для предотвращения лишних ререндеров.
  - **useEffect:** выполнение побочных эффектов, таких как вызов API.
  - **useRef:** создание изменяемой ссылки для отслеживания анимации прокрутки.
  - **useMemo:** оптимизация вычислений (например, фильтрация списка по поисковому запросу).

- **React Native компоненты:**  
  ```js
  import { View, TextInput, StyleSheet, FlatList, Animated, Text, Alert } from "react-native";
  ```  
  Компоненты для построения пользовательского интерфейса:
  - **View:** базовый контейнер.
  - **TextInput:** поле ввода для поиска.
  - **FlatList:** оптимизированный список для отображения криптовалют.
  - **Animated:** работа с анимациями (в данном случае для плавного скрытия поисковой строки).
  - **Text:** вывод текстовой информации (например, ошибок).
  - **Alert:** показ всплывающих сообщений об ошибках.

- **Axios:**  
  ```js
  import axios from "axios";
  ```  
  Используется для выполнения HTTP-запросов к API с целью получения актуальных данных о криптовалютах.

- **useFocusEffect:**  
  ```js
  import { useFocusEffect } from "@react-navigation/native";
  ```  
  Хук, позволяющий выполнять функцию при каждом входе на экран (полезно для обновления данных при возвращении на экран).

- **LinearGradient:**  
  ```js
  import { LinearGradient } from "expo-linear-gradient";
  ```  
  Компонент для создания градиентного фона, используемый в оформлении поисковой панели.

- **MaterialCommunityIcons:**  
  ```js
  import { MaterialCommunityIcons } from "@expo/vector-icons";
  ```  
  Библиотека иконок, здесь используется иконка для поля поиска.

- **Локальные компоненты и данные:**  
  ```js
  import CryptoCard from "../components/CryptoCard";
  import icons from "../../data/icons";
  ```  
  - **CryptoCard:** компонент для отображения информации о криптовалюте (символ, цена, процент изменения и иконка).
  - **icons:** объект, содержащий иконки для различных криптовалют, используется для подстановки нужной иконки по символу.

## Основные функции и хуки

### Функция **fetchData**
Используется для получения данных с API:
- Выполняет GET-запрос через Axios.
- Обрабатывает пустые данные, выводит предупреждение в консоль и устанавливает состояние ошибки.
- При успешном получении данных сохраняет их в состоянии `cryptoData` (преобразует объект в массив пар [ключ, значение]).
- В случае ошибки выводит сообщение об ошибке в консоль, устанавливает состояние ошибки и вызывает всплывающее окно с предупреждением.
  
```js
const fetchData = useCallback(async () => { ... }, []);
```

### **useEffect**
- Вызывается при монтировании компонента.
- Вызывает `fetchData` для первоначальной загрузки данных.
- Устанавливает интервал обновления данных каждые 10 секунд.
- Очищает интервал при размонтировании компонента.

```js
useEffect(() => { ... }, [fetchData]);
```

### **useFocusEffect**
- Обновляет данные всякий раз, когда экран становится активным (например, при возврате на него из другого экрана).

```js
useFocusEffect(
  useCallback(() => {
    fetchData();
  }, [fetchData])
);
```

### **handleSearch**
- Обработчик ввода текста в поисковую строку.
- Обновляет состояние `searchQuery` в зависимости от введённого текста.

```js
const handleSearch = useCallback((text) => {
  setSearchQuery(text);
}, []);
```

### **displayedData (useMemo)**
- Мемоизированное вычисление списка криптовалют для отображения.
- Если поисковый запрос пуст, возвращается весь список.
- В противном случае – фильтруется список по совпадению символа с поисковым запросом (без учёта регистра).

```js
const displayedData = useMemo(() => { ... }, [cryptoData, searchQuery]);
```

### **handleToggleFavorite**
- Обработчик для переключения статуса избранного элемента.
- Если криптовалюта уже в избранном, удаляет её, иначе – добавляет.
- Использует функцию обновления состояния, копируя предыдущий объект избранного и внося изменения.

```js
const handleToggleFavorite = useCallback((symbol) => { ... }, []);
```

### **renderItem**
- Функция для рендера каждого элемента списка.
- Распаковывает элемент в `symbol` и `data`.
- Выбирает соответствующую иконку из объекта `icons` (если нет – используется иконка для "btc").
- Возвращает компонент **CryptoCard** с необходимыми пропсами: символ, цена, изменение цены, иконка, статус избранного и обработчик для переключения избранного.

```js
const renderItem = useCallback(({ item }) => { ... }, [favorites, handleToggleFavorite]);
```

### Анимация поиска
- **searchBarOpacity**: Анимированное значение, изменяющее прозрачность поисковой строки при прокрутке.
- Используется метод `interpolate` для изменения значения от 1 до 0 при прокрутке от 0 до 50 пикселей.

```js
const searchBarOpacity = scrollY.interpolate({ ... });
```

## Компоненты

### HeaderComponent

Компонент **HeaderComponent** отвечает за отрисовку верхней части экрана:
- **Секция профиля:**  
  Отображает аватар (с использованием изображения по URL) и имя пользователя.
- **Уведомления:**  
  Кнопка с иконкой звонка и маленьким индикатором уведомлений (красный кружок).
- **Секция баланса:**  
  Отображает общий баланс и динамику изменения с помощью градиентного фона.
- **Слайдер кошельков:**  
  Горизонтальный ScrollView, в котором для каждого кошелька создается карточка с информацией (название, баланс и доход). Карточки оформляются с использованием градиента.
- **Экспериментальная поисковая строка:**  
  Содержит иконку поиска, поле ввода (TextInput) и кнопку очистки. Значение поля ввода управляется через свойства `searchText` и `setSearchText`, переданные из родительского компонента.
- **Заголовок секции избранных криптовалют:**  
  Простой текстовый заголовок, обозначающий начало списка избранных монет.

Аргументы:
- `searchText` — текущий текст поискового запроса.
- `setSearchText` — функция для обновления поискового запроса.

### renderFavoriteCoin

Функция для рендеринга отдельной карточки избранной криптовалюты:
- Отображает:
  - Иконку (иконка валюты USD используется в качестве примера).
  - Название криптовалюты.
  - Текущую цену.
  - Изменение цены с цветовым выделением:  
    - Зеленым для положительного изменения.
    - Красным для отрицательного изменения.

Аргумент:
- `item` — объект, содержащий данные о криптовалюте (id, name, price, change).

### HomeScreen

Основной компонент экрана:
- Управляет состоянием поискового запроса через хук `useState`.
  ```js
  const [searchText, setSearchText] = useState("");
  ```
- **Фильтрация данных:**  
  На основе введенного текста из поисковой строки производится фильтрация массива `favoriteCoinsData`. Фильтрация нечувствительна к регистру.
  ```js
  const filteredCoins = favoriteCoinsData.filter(coin => 
    coin.name.toLowerCase().includes(searchText.toLowerCase())
  );
  ```
- **Разметка:**  
  Экран обернут в **LinearGradient** для создания стильного фона. Список избранных криптовалют рендерится через **FlatList**:
  - **ListHeaderComponent** содержит весь HeaderComponent (профиль, баланс, кошельки, поисковая строка и заголовок избранных).
  - `data` для **FlatList** — это отфильтрованный список избранных монет.
  - **renderItem** — функция рендеринга для каждой карточки монеты.
  - Дополнительные стили задаются через `contentContainerStyle`.

## Логика и функциональность компонента

### Общий баланс портфеля

- **Расчет общего баланса:**  
  Выполняется с использованием метода `reduce` по массиву активов. Общий баланс вычисляется как сумма произведений количества и цены каждого актива:
  ```js
  const totalBalance = portfolioAssets.reduce(
    (acc, asset) => acc + asset.balance * asset.value,
    0
  );
  ```

### Анимация изменения баланса

- **Анимированное значение:**  
  Создается с помощью `useRef` и инициализируется значением 0.  
  ```js
  const animatedValue = useRef(new Animated.Value(0)).current;
  ```

- **useEffect для анимации:**  
  При монтировании компонента запускается анимация с использованием `Animated.timing`, которая плавно изменяет значение до `totalBalance` за 1500 мс. Во время анимации подписчик обновляет состояние `displayedBalance`:
  ```js
  useEffect(() => {
    Animated.timing(animatedValue, {
      toValue: totalBalance,
      duration: 1500,
      useNativeDriver: false,
    }).start();

    const id = animatedValue.addListener(({ value }) => {
      setDisplayedBalance(value);
    });

    return () => {
      animatedValue.removeListener(id);
    };
  }, [totalBalance]);
  ```

### График динамики портфеля

- **LineChart:**  
  Компонент графика, отображающий динамику портфеля. Использует данные из `chartData`, конфигурацию графика `chartConfig` и ширину, вычисленную на основе размеров экрана:
  ```js
  <LineChart
    data={chartData}
    width={SCREEN_WIDTH - 32}
    height={220}
    chartConfig={chartConfig}
    bezier
    style={styles.chartStyle}
  />
  ```

### Список активов

- **Рендеринг карточек активов:**  
  Для каждого актива из `portfolioAssets` создается интерактивная карточка с помощью компонента **TouchableOpacity**:
  - При нажатии происходит навигация к экрану деталей актива с передачей соответствующих данных.
  - Каждая карточка отображает:
    - Иконку актива.
    - Название и баланс актива.
    - Стоимость актива (рассчитанную как произведение баланса и цены).
    - Процент изменения цены, с условным оформлением:
      - Зеленый цвет для положительного изменения.
      - Красный цвет для отрицательного изменения.
  ```js
  {portfolioAssets.map((asset) => (
    <TouchableOpacity
      key={asset.id}
      style={styles.assetCard}
      activeOpacity={0.85}
      onPress={() => navigation.navigate("AssetDetails", { asset })}
    >
      {/* Информация об активе */}
      <View style={styles.assetInfo}>
        <MaterialCommunityIcons
          name={asset.icon || "currency-usd-circle-outline"}
          size={30}
          color="#fff"
        />
        <View style={styles.assetText}>
          <Text style={styles.assetName}>{asset.name}</Text>
          <Text style={styles.assetBalance}>
            {asset.balance} {asset.symbol}
          </Text>
        </View>
      </View>
      {/* Статистика по активу */}
      <View style={styles.assetStats}>
        <Text style={styles.assetValue}>
          ${(asset.balance * asset.value).toFixed(2)}
        </Text>
        <Text
          style={[
            styles.assetChange,
            asset.change >= 0 ? styles.positive : styles.negative,
          ]}
        >
          {asset.change >= 0 ? `+${asset.change}%` : `${asset.change}%`}
        </Text>
      </View>
    </TouchableOpacity>
  ))}
  ```

  Используются для создания компонента, работы со ссылками (анимационные значения), управления состоянием (локальное состояние избранного) и выполнения побочных эффектов (запуск анимации).

- **React Native компоненты:**  
  ```js
  import { Animated, PanResponder, View, Text, StyleSheet, Dimensions } from 'react-native';
  ```  
  - **Animated:** позволяет реализовывать анимационные эффекты (например, перемещение и масштабирование).
  - **PanResponder:** обрабатывает жесты пользователя (свайпы) для управления анимацией.
  - **View, Text:** базовые компоненты для создания структуры и отображения текста.
  - **StyleSheet:** создание стилей.
  - **Dimensions:** получение размеров экрана (используется для адаптивной вёрстки, хотя в данном случае используется только ширина экрана для константы).

- **Иконки MaterialCommunityIcons:**  
  ```js
  import MaterialCommunityIcons from '@expo/vector-icons/MaterialCommunityIcons';
  ```  
  Библиотека для отображения иконок. Здесь используется иконка звезды для обозначения статуса "избранное" иконка может менять цвет в зависимости от состояния.

## Константы и параметры

- **Экран и пороговые значения свайпа:**
  ```js
  const { width: SCREEN_WIDTH } = Dimensions.get('window');
  const MAX_DRAG_DISTANCE = 120;
  const THRESHOLD_RATIO = 0.9;
  const THRESHOLD = MAX_DRAG_DISTANCE * THRESHOLD_RATIO;
  ```  
  - **MAX_DRAG_DISTANCE:** максимальное расстояние, на которое можно сдвинуть элемент.
  - **THRESHOLD:** пороговое значение (90% от максимального), после которого считается, что свайп завершен и нужно переключить состояние избранного.

## Логика компонента

### Состояния и анимированные значения

- **Локальное состояние isFavorite:**  
  Компонент получает состояние избранного через пропс `propFavorite` и синхронизирует его с локальным состоянием `isFavorite`:
  ```js
  const [isFavorite, setIsFavorite] = useState(propFavorite);
  ```
  При изменении пропса происходит обновление состояния через `useEffect`.

- **Анимированное значение translateX:**  
  Используется для перемещения свайповой части карточки:
  ```js
  const translateX = useRef(new Animated.Value(0)).current;
  ```

- **Анимированное значение starScale:**  
  Управляет масштабированием звезды при изменении состояния избранного:
  ```js
  const starScale = useRef(new Animated.Value(1)).current;
  ```

### Синхронизация состояния избранного

- **Обновление локального состояния при изменении пропса:**
  ```js
  useEffect(() => {
    setIsFavorite(propFavorite);
  }, [propFavorite]);
  ```
  Это гарантирует, что при внешнем изменении состояния избранного, локальное состояние будет обновлено.

- **Анимация изменения звезды:**  
  При каждом изменении `isFavorite` запускается последовательная анимация, которая сначала увеличивает масштаб звезды до 1.5, затем возвращает его к 1:
  ```js
  useEffect(() => {
    Animated.sequence([
      Animated.timing(starScale, {
        toValue: 1.5,
        duration: 150,
        useNativeDriver: true,
      }),
      Animated.timing(starScale, {
        toValue: 1,
        duration: 150,
        useNativeDriver: true,
      }),
    ]).start();
  }, [isFavorite, starScale]);
  ```

### Обработка жестов с помощью PanResponder

- **Инициализация PanResponder:**  
  Создается объект `panResponder` для обработки свайпов:
  ```js
  const panResponder = useRef(
    PanResponder.create({
      onStartShouldSetPanResponder: () => true,
      onPanResponderMove: (_, gestureState) => { ... },
      onPanResponderRelease: (_, gestureState) => { ... },
      onPanResponderTerminate: () => { ... },
    })
  ).current;
  ```
  
- **onPanResponderMove:**  
  Обрабатывается горизонтальное перемещение:
  - **dx:** вычисляется как положительное значение (свайп вправо).
  - Значение `translateX` ограничивается максимальным значением `MAX_DRAG_DISTANCE`:
    ```js
    const dx = Math.max(0, gestureState.dx);
    const clamped = Math.min(dx, MAX_DRAG_DISTANCE);
    translateX.setValue(clamped);
    ```

- **onPanResponderRelease:**  
  При отпускании жеста проверяется, превышает ли смещение пороговое значение:
  - Если значение больше порога, запускается анимация перемещения до максимума и затем возвращения в исходное положение. По завершении анимации происходит переключение состояния избранного:
    ```js
    if (dx >= THRESHOLD) {
      Animated.sequence([
        Animated.timing(translateX, {
          toValue: MAX_DRAG_DISTANCE,
          duration: 150,
          useNativeDriver: true,
        }),
        Animated.timing(translateX, {
          toValue: 0,
          duration: 150,
          useNativeDriver: true,
        }),
      ]).start(() => {
        const newFavoriteState = !isFavorite;
        setIsFavorite(newFavoriteState);
        onToggleFavorite && onToggleFavorite(symbol, newFavoriteState);
      });
    } else { ... }
    ```
  - Если значение меньше порога, элемент возвращается в исходное положение:
    ```js
    Animated.timing(translateX, {
      toValue: 0,
      duration: 150,
      useNativeDriver: true,
    }).start();
    ```

- **onPanResponderTerminate:**  
  Если жест был прерван, элемент возвращается в исходное положение:
  ```js
  Animated.timing(translateX, {
    toValue: 0,
    duration: 150,
    useNativeDriver: true,
  }).start();
  ```

### Верстка компонента

- **Структура компонента:**  
  Компонент состоит из двух основных частей:
  1. **Фиксированная звезда (starContainer):**  
     Отображается позади свайповой части и показывает, является ли криптовалюта избранной (цвет меняется в зависимости от состояния).
  2. **Свайповая часть карточки (frontLayer):**  
     Отображает основную информацию:
     - Иконка криптовалюты (если передан компонент через `IconComponent`).
     - Информация о криптовалюте: символ (приводится к верхнему регистру), цена (с округлением) и процентное изменение (с условным оформлением: зелёным для положительных и красным для отрицательных значений).

- **Применение анимации:**  
  Свайповая часть обернута в `Animated.View` с привязанным значением `translateX`, что позволяет перемещать карточку в горизонтальном направлении.

## Стили (StyleSheet)

- **cardContainer:**  
  Определяет внешний вид карточки: отступы, высоту, скругленные углы, тень и цвет фона.
  
- **starContainer:**  
  Позиционирует иконку звезды слева от свайповой части. Используется абсолютное позиционирование.
  
- **frontLayer:**  
  Основной слой карточки, который свайпается. Имеет фон, высоту, скругленные углы и zIndex для корректного наложения.
  
- **innerContent, iconContainer, info:**  
  Определяют расположение содержимого внутри карточки: иконка криптовалюты, название, цена и изменение.
  
- **Стили для текста:**  
  - **symbol:** для символа криптовалюты (большой и жирный шрифт).
  - **price:** для отображения цены.
  - **change:** для отображения процентного изменения, дополненное стилями **positive** (зелёный) и **negative** (красный) для условного оформления.

## Итог

Файл **CryptoCard.js** реализует интерактивную карточку криптовалюты с функционалом свайпа для переключения состояния "избранное". Ключевые моменты:
- **Анимация свайпа:** обеспечивает интуитивное взаимодействие пользователя.
- **Изменение состояния избранного:** сопровождается анимацией масштабирования звезды.
- **Пан-обработчик:** обрабатывает жесты пользователя и определяет, когда изменить состояние на основе заданного порога.
